DeltaBlade shop images
======================
Put one PNG per shop item here: 128x128 pixels, transparent background, pixel-art style.
If a file is missing, the shop uses an existing game image (or shows "NO IMAGE").

Expected file names:
  shop_needle_laser.png   (Needle Laser)   - no fallback yet
  shop_twin_beam.png      (Twin Beam)      - no fallback yet
  shop_sweep_laser.png    (Sweep Laser)    - no fallback yet
  shop_arc_lance.png      (Arc Lance)      - no fallback yet
  shop_plasma_orb.png     (Plasma Orb)     - no fallback yet
  shop_double.png         (Double Shot)    - fallback: pickup_weapon.png
  shop_triple.png         (Triple Shot)    - fallback: pickup_weapon.png
  shop_quad.png           (Quad Shot)      - fallback: pickup_weapon.png
  shop_extra_life.png     (Extra Life)     - fallback: heart.png
  shop_extra_time.png     (Extra Time)     - fallback: pickup_time.png
  shop_extra_ammo.png     (Extra Ammo)     - fallback: pickup_ammo.png
  shop_autofire.png       (Autofire)       - fallback: pickup_autofire.png
